一个热系统：状态正在连续地变化（示意图，不显示任何数字）

如果 θ 只是编号，我们当然可以随便给每个状态编号。

但相近的物理状态，应该能够对应相近的数值。

状态发生连续变化时，温度表示也应该能够连续变化。

重新标度：θ′ = 2θ + 5

[A] [C] [G]

θ = 20 → θ′ = 45

与它最接近的类别：[A]

例如 20 → 45、50 → 105、80 → 165。

重新标度可以改变数字，但不会改变系统之间的热平衡关系。

三把抽象的“尺子”（它们描述的是同一批有序状态）

尺子 A 0 10 20 30
尺子 B 0 100 200 300
尺子 C −20 0 20 40

点一下某把尺子可以把它藏起来，比较刻度疏密与零点位置。

数字本身不是热平衡关系。

真正不变的是：哪些状态彼此热平衡，以及状态之间的大小规律。
