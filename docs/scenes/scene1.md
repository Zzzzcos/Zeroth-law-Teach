# 第一幕 · 一个看似合理的证明

## 目标

**只制造怀疑，不解决问题。** 本幕唯一任务：让学生怀疑"温度"是不是被偷偷预设了。

学生应产生："等等，我们是不是已经偷偷使用了温度？"

## 台词（照抄，不要改写措辞）

- 引导句：先看一个看起来很自然的推理。
- 逻辑链节点（自上而下）：温度相等 / 热平衡 / 温度相等
- 结论句：因此，第零定律证明了温度的存在。
- 疑问阶段依次出现：① 真的是这样吗？ ② 仔细看看这个推理。 ③ 我们真的从头到尾都没有使用"温度"吗？
- 按钮：重新检查这个证明 →

## 交互

- 疑问阶段可逐个悬停 / 键盘聚焦链上的每一步：该节点恢复清晰，并显示一个**引导性提问**（只提问，绝不给答案）：
  - 节点 1：这一步的"温度"从哪儿来？
  - 节点 2：这里的"热平衡"是用什么定义的？
  - 节点 3：这个结论是怎么得到的？
- 按钮 → 进入第二幕；第二幕未实现时显示交接说明（"下一幕：去掉温度，只留下热平衡关系"），不得提前解释本幕答案。
- 重播：按钮 + 快捷键 `R`；`Enter` 继续。支持 `prefers-reduced-motion`。

## 本幕红线：不得出现

"循环论证"四个字；等价关系；等价类；θ；经验温度；温标；`T_A = T_B`；以及任何解释"这个推理错在哪里"的文字。**第一幕只提问，不回答。**
