# 第四幕 · 同一个温度，可以有不同的数字吗？

> 幕级切片：可单独投喂给一个新会话实现本幕。代码风格与文件结构基准见 `docs/scenes/scene1.md`。

## 目标

学生自己发现：**这些数字其实不是唯一的。**

故事线：换数字 → 分类仍然不变 → 什么样的换法可以接受？→ 单射 → 双射 → 保持冷热大小规律（严格递增）→ 仍然缺少具体物理规律。

**不要直接从数学函数开始**：先让用户手动"换一种标记"，再引入 `θ' = f(θ)`。

## 台词与画面（照抄，不要改写措辞）

- 起始复用：`[A] → 20`、`[C] → 50`、`[G] → 80`
- 按钮：换一种标记
  - 第一次点击：`[A] → 2`、`[C] → 5`、`[G] → 8`
  - 第二次点击：`[A] → 40`、`[C] → 100`、`[G] → 160`
- 每次变化时，热平衡等价类本身不发生变化 → **数字变了，但热平衡分类没有变。**
- 现在才出现：`θ' = f(θ)`，例如 `θ' = 2θ` → `20 → 40`、`50 → 100`、`80 → 160`
- 同时显示 `A ∼ B`，仍然对应 `θ(A) = θ(B)`，也对应 `θ'(A) = θ'(B)`
- 重新标度没有改变热平衡分类。
- 错误标度：`f(20) = 10`、`f(50) = 10` → `[A]` 与 `[C]` 在视觉上撞在一起
- 发生了什么？
- 两个原本不同的热平衡等价类，被压成了同一个数字。
- 强调：**分类信息丢失了。**
- 结论（方框）：`f 至少需要是单射`；数学表达：`θ₁ ≠ θ₂ ⇒ f(θ₁) ≠ f(θ₂)`
- 追问：如果我们不只是希望"不能合并"，而是希望建立一套完整的新温度标度呢？
- 设 `f : Θ → Θ'`：每一个旧温度对应一个新温度；每一个新温度也都应该对应某一个旧温度。
- 结论（方框）：`f 是双射`
  - 单射：不能把不同的旧温度合并
  - 满射：新的温度集合中不能出现无法对应旧温度的值
  - 两者合起来：双射
- 追问：数字大小只是编号吗？
- 假设 `θ_A < θ_B`，例如 `20 < 50`；若 `θ' = 2θ + 5`，则 `20 → 45`、`50 → 105`、`80 → 165`，大小规律保持。
- 结论（方框）：`f 严格递增`
- 反例：`θ' = -θ` → `20 → -20`、`50 → -50`；原来 `20 < 50`，新的数值 `-20 > -50`
- 数值顺序被反转了。
- 准确说明：它仍然是一一对应的重新标度，但如果我们要求数值大小规律保持原来的冷热大小规律，这种变换就不符合要求。
- 收束：屏幕中央 `θ` + "我们已经有了一个可以表示热平衡类别的数值标签。"；随后 `θ' = f(θ)`
- 但第零定律并没有告诉我们：零点在哪里 / 单位是什么 / 一个单位应该有多大 / 各个刻度之间如何确定 / θ 与其他物理量具体满足什么关系
- 框架图：`第零定律 → 热平衡分类结构`；而 `具体温标 ← 额外物理规律 + 标度规定`
- 举例（**不深入推导**）：理想气体温标可利用 `PV = nRT`；热力学温标需要第二定律以及可逆热机关系。
- 最终总结链（竖向）：热平衡 ↓ 第零定律 ↓ 等价关系 ↓ 热平衡等价类 ↓ 数值标签 ↓ θ ↓ 重新标度 `θ' = f(θ)` ↓ 具体物理规律 + 标度规定 ↓ **具体温标**
- 最后一句：**第零定律给了我们"温度可以用来区分热平衡类别"的结构，但没有单独给出温度的具体尺子。**

## 交互

- "换一种标记"可循环三组数字（20/50/80 → 2/5/8 → 40/100/160），热平衡分类始终不变；**8 秒没人点就自动演示**。
- 相撞实验用**数轴 + 滑块**：`[C]` 固定在 10，把 `[A]` 拖到 10，两个标记叠在一起并轻微脉冲，触发"两个类别被压成同一个数字"；**8 秒没人拖就自动把滑块推过去**。
- 单调性用**分段按钮**在 `θ′ = 2θ + 5` 与 `θ′ = −θ` 之间切换，对照行（`20 < 50` → `45 < 105` 或 `−20 > −50`）随之更新。
- 重播后必须回到：标签 20/50/80、滑块在 40、分段按钮回到 `2θ + 5`、映射表空白。

## 本幕红线：不得出现

- "严格单调函数一定是双射"
- "`θ' = -θ` 在数学上不是合法的温标变换"（必须说成：仍是一一对应的重新标度，只是不满足"保持冷热大小规律"这一额外要求）
- "`θ' = f(θ)` 中的 f 必须天然是双射"
- 第二定律的深入推导

## 物理精度要点

- 严格单调 ⇒ **单射**；是否双射还取决于定义域、陪域以及是否满足满射。
- 三层要求必须区分清楚：
  1. 只要求"不合并不同类别" → **单射**
  2. 要求新旧标度完整一一对应 → **双射**
  3. 还要求数值大小规律保持冷热大小规律 → **严格递增的双射**
- 本幕结束时必须留下"第零定律仍然没有给出具体刻度"这个缺口。
