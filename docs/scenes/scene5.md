# 第五幕 · 一把尺子究竟要满足什么要求？

> 幕级切片：可单独投喂给一个新会话实现本幕。代码风格与文件结构基准见 `docs/scenes/scene1.md`。

## 目标

第四幕已经发现 `θ' = f(θ)`：不同的数值标度可能描述同一个热平衡结构。

本幕**不再增加抽象数学**，而是通过"测量一个物理量"的直觉，让学生理解：**一个温标不仅仅是在给状态编号，它还应该能够稳定、连续地描述冷热状态。**

## 台词与画面（照抄，不要改写措辞）

- 幕首画面：一个热系统（密闭系统 + 可变化的状态指示，或热源与系统的简单示意）。
- 系统经历：冷 → 较冷 → 中等 → 较热 → 热
- **不要直接显示温度数字**，只显示一个连续变化的状态；随着状态连续变化，一个抽象的指示器也连续移动。
- 提问：如果 θ 只是编号，我们当然可以随便给每个状态编号。
- 但物理测量还要求：**相近的物理状态，应该能够对应相近的数值。**
- 以及：**状态发生连续变化时，温度表示也应该能够连续变化。**
- （这里不需要严格建立"连续函数"的数学理论，只需要给学生建立直觉。）
- 重新标度实验：`θ' = 2θ + 5` → `20 → 45`、`50 → 105`、`80 → 165`
- 滑块：让学生拖动 θ，观察 θ' 同步变化；显示 `θ' = f(θ)`
- 让学生看到：重新标度可以改变数字，但不会改变系统之间的热平衡关系。
- 三把抽象的"尺子"（**不要把这些直接等同于真实温标**）：

```text
尺子 A
0 ─── 10 ─── 20 ─── 30

尺子 B
0 ───── 100 ───── 200 ───── 300

尺子 C
-20 ─── 0 ─── 20 ─── 40
```

- 它们只是说明：**不同数值标度可以描述相同的有序状态。**
- 强调：数字本身不是热平衡关系。
- 真正不变的是：哪些状态彼此热平衡，以及状态之间的大小规律。
- 小结：方框 `热平衡结构` 与方框 `温度数值表示` 之间的关系
  - 热平衡结构告诉我们"哪些状态可以归为同一类"。
  - 温度标度进一步给这些类别安排数值。
- 幕末提问：**那么，物理学为什么最终采用某些特定的温标？**（进入第六幕）

## 交互

- 状态指示器由 **requestAnimationFrame** 驱动（0 → 1 → 0，约 6 秒一个来回）；屏幕上**不出现任何数字**，只给"冷 / 较冷 / 中等 / 较热 / 热"五个定性词。
- θ 滑块（0–100，步长 5）：实时显示 `θ` 与 `θ′ = 2θ + 5`，并在刻度条上给出"与它最接近的类别"（`[A]` / `[C]` / `[G]`），让学生看到**数字在变、类别指示不变**。
- 三把尺子（0–30 / 0–300 / −20–40）**点击可藏**（也支持键盘 Enter / Space），用于比较刻度疏密与零点位置。
- 重播后必须回到：指示器停在"中等"、滑块回到 20、三把尺子全部可见、所有文字回到未出现状态。

## 本幕红线：不得出现

- 把三把尺子说成摄氏、华氏、开尔文（它们只是抽象刻度）
- 把尺子 C 的负值说成"摄氏的负温度"
- 熵、统计物理、热力学势
- 声称"严格单调一定双射"

## 物理精度要点

- 连续性只建立**直觉**，不建立严格数学理论，也不得声称"第零定律蕴含连续性"。
- `θ' = 2θ + 5` 的算术必须正确：`20 → 45`、`50 → 105`、`80 → 165`。
- 是否采用连续 / 单调的重新标度，属于**额外的标度选择**，不是等价关系的数学产物。
- 本幕结束时缺口仍然是："具体采用哪把尺子，第零定律没有回答。"
