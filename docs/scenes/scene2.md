# 第二幕 · 去掉温度：只留下热平衡关系

> 幕级切片：可单独投喂给一个新会话实现本幕。代码风格与文件结构基准见 `docs/scenes/scene1.md`。

## 目标

学生上一幕已经怀疑"温度"是被预设的。本幕直接做一个思想实验：**如果暂时禁止使用"温度"，我们还能说什么？**

学生应能说出："即使不使用温度，我仍然可以讨论热平衡。"

## 台词与画面（照抄，不要改写措辞）

- 幕首提问：如果暂时禁止使用"温度"，我们还能说什么？
- 画面：系统 A、系统 B，允许进行热接触 → `[ A ] ←→ [ B ]`
- 过程动画：接触 → 开始交换热量 → 交换的幅度逐渐减弱 → 最终停止。**不要使用大量热量粒子动画。**
- 曲线图（纵轴 = A 与 B 之间的热流量；**零线 = 没有热量交换**）：
  - 接触之前，两条曲线都停在零线上；
  - 接触之后，两条曲线分别向零线两侧张开（A 放热 / B 吸热），幅度先增后减；
  - **最后重新并回零线：两条曲线合成一条**；用一条虚线标出"并回零线"的时刻；
  - 曲线与零线之间的**阴影面积 = 交换的总热量（不为 0）**。
- 定义（动画停止后出现，三行依次出现）：
  - 经过足够长时间后，宏观状态不再发生变化。
  - **两者之间没有净热量交换。**（单独强调：深蓝字 + 浅蓝底，紧跟上一句出现）
  - 我们称 A 与 B 处于热平衡。
- 记法：`A ∼ B`，旁注：A 与 B 处于热平衡。
- 强调：**注意：这里没有使用"温度"来定义热平衡。**
- 引入第三方系统 C：先 `A ∼ C`，再 `B ∼ C`，画面形成 `A —— C —— B`
- 追问：那么 A 和 B 呢？（停顿）
- 出现：`A ∼ B`
- 这正是热力学第零定律的核心内容。
- 正式形式：`A ∼ C,  B ∼ C  ⟹  A ∼ B`
- 三个性质逐个出现：
  - `A ∼ A`｜一个系统与自身处于热平衡。→ **自反性**
  - `A ∼ B ⇒ B ∼ A`｜热平衡关系是对称的。→ **对称性**
  - `A ∼ C,  B ∼ C ⇒ A ∼ B`｜旁注"第零定律" → **传递性**
- 聚合动画：自反性 ✓、对称性 ✓、传递性 ✓ 三个词向中央聚合
- 结论（方框）：`热平衡关系是一种等价关系`
- 补一句：我们原本只是在描述"哪些系统彼此处于热平衡"，现在却发现这种关系具有特殊的数学结构。
- 幕末提问：这种等价关系，把所有系统分成了什么？
- 按钮：看看它如何分类 →

## 本幕红线：不得出现

- `T_A = T_B`，或任何形式的“温度相等”
- **只凭**“没有热量传递 / 没有净热量交换”就判定热平衡（反例：两个绝热隔离的系统也没有热量传递，但它们并没有热平衡）
- 把“热量从温度高的流向低温的”当作解释（那等于偷偷把温度当作已知量）
- θ、经验温度、温标、**等价类**（本幕只到“等价关系”为止）
- “因为没有热量传递，所以 A 与 B 热平衡”

## 物理精度要点

- **热平衡的完整定义（三条件缺一不可）**：允许进行热接触 + 经过足够长时间后宏观状态不再发生变化 + 两者之间没有净热量交换 ⇒ 处于热平衡。记作 `A ∼ B`。
  - 为什么必须加上“没有净热量交换”：只要求“宏观状态不再变化”会漏掉**稳态热传导**（A、B 的状态不变，但热量一直在穿过它们）。
  - 为什么必须保留“允许热接触”：否则两个绝热隔离的系统也会被算作热平衡。
- 曲线上体现的是**热流量**：接触前为 0 → 接触后先升后降 → 最后回到 0（两条曲线并回零线）。曲线与零线之间的**阴影面积 = 交换的总热量（不为 0）**：交换会在有限时间内停止，但已经交换的总量不为 0。
- 第零定律采用 `A ∼ C, B ∼ C ⟹ A ∼ B` 形式（体现传递性）。
- 自反性、对称性、传递性只是**关系**的性质；**它们本身不会自动产生一个数字**。本幕不得暗示“所以可以编号”。
- 本幕只允许给到结论“热平衡关系是一种等价关系”。
