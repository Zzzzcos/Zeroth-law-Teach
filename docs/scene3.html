[A] = {A, B, D}

[C] = {C, E, F}

[G] = {G, H}

热平衡关系把系统状态分成了若干个互不重叠的类别。

每一个类别，就是一个热平衡等价类。

我们已经能够按热平衡关系分类。

如果希望用一个数字标记每一个类别呢？

这些数字是我们给类别贴上的标签，不是热平衡关系本身自动产生的。

θ(A) = θ(B) = θ(D) = 20

不同的系统状态可以拥有相同的 θ。

因为它们属于同一个热平衡等价类。

A ∼ B ⟺ θ(A) = θ(B)

θ 是对热平衡等价类的一种数值表示。

这样的 θ 可以作为一种“经验温度”。

θ 不是系统状态与实数之间的一一对应。

热平衡等价类 ⟷ 温度数值标签

为什么是 20、50、80？

为什么不是 2、5、8？

为什么不是 40、100、160？

温度有了，但具体的“刻度”还没有。
