第二幕：去掉温度，只留下热平衡关系

如果暂时禁止使用“温度”，我们还能说什么？

系统 A
系统 C
系统 B

点击“允许热接触”，让 A 与 B 接触。

经过足够长时间后，宏观状态不再发生变化。

两者之间没有净热量交换。

我们称 A 与 B 处于热平衡。

注意：这里没有使用“温度”来定义热平衡。

A ∼ B 直接热接触得到

A ∼ C A 与 C 处于热平衡

B ∼ C B 与 C 处于热平衡

那么 A 和 B 呢？

A ∼ B 由上面两行与第零定律得到

这正是热力学第零定律的核心内容。

A ∼ C,  B ∼ C ⟹ A ∼ B

热力学第零定律

A ∼ A

一个系统与自身处于热平衡。

自反性✓

A ∼ B ⇒ B ∼ A

热平衡关系是对称的。

对称性✓

A ∼ C, B ∼ C ⇒ A ∼ B

这正是第零定律的内容。

传递性✓

热平衡关系是一种等价关系

我们原本只是在描述“哪些系统彼此处于热平衡”，现在却发现这种关系具有特殊的数学结构。
